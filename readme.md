# Curso de Análisis de Algoritmos

Repositorio utilizado durante el semestre para almacenar los ejercicios de clase, laboratorios evaluativos y herramientas de apoyo desarrolladas en el curso de **Análisis de Algoritmos**.

## Estructura del repositorio

El repositorio está organizado de la siguiente manera:

- `laboratorios/`: contiene los cinco laboratorios evaluativos desarrollados durante el semestre.
- `ejercicios-clase/`: contiene ejercicios, ejemplos y código realizado durante las sesiones prácticas.
- `benchmarks/`: contiene scripts utilizados para medir tiempos de ejecución, realizar comparaciones y generar resultados experimentales.
- `.gitignore`: define archivos y carpetas que no deben incluirse en el control de versiones.
- `README.md`: contiene la documentación general del repositorio.

## Uso del repositorio

Para descargar una copia local del repositorio se puede utilizar:

```bash
git clone <URL_DEL_REPOSITORIO>
```

Después de realizar cambios, el flujo básico de trabajo será:

```bash
git status
git add .
git commit -m "Descripción del cambio"
git push
```

## Laboratorios

Los informes evaluativos serán almacenados dentro de la carpeta `laboratorios/`, utilizando una carpeta independiente para cada entrega.

Ejemplo:

```text
laboratorios/
├── laboratorio-01/
├── laboratorio-02/
├── laboratorio-03/
├── laboratorio-04/
└── laboratorio-05/
```
